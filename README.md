# LLM Epistemic Boundaries

This repository contains structured experiments examining how large language models
handle premise acceptance, reassurance, and epistemic boundary enforcement.

The work focuses on:
- Premise acceptance under user reassurance
- Boundary degradation across prompt escalation
- Behavioral variance across deployed models

All experiments are conducted manually in clean sessions unless explicitly stated.
This repository prioritizes documentation, reproducibility, and ethical framing.

## Ethics

This research does not seek to exploit systems or bypass safeguards, but to
document observable behaviors relevant to safety, governance, and deployment risk.
